# audio-meeting-transcript

> 来源分类：**市场技能** ｜ 导出批次：published

录音转写技能——将音频转为带说话人识别和时间戳的录音稿，并生成会议纪要。类似飞书"妙记"。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/audio-meeting-transcript__skillhub        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/audio-meeting-transcript__skillhub   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
